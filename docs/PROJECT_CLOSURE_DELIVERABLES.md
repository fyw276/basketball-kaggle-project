# 衣服穿搭决策助手项目收尾交付说明

## 1. 项目主线

本项目最终不再按“功能集合”讲解，而按一条购买决策主线讲解：

> 基于服饰图像识别与用户画像的购买决策助手，帮助用户判断一件衣服是否和已有衣物重复、是否适合自己、是否值得购买。

核心闭环固定为：

1. 看懂衣服：上传服饰图片，识别品类、颜色、风格，并提取图像特征向量。
2. 看像不像：将待购买单品与衣橱已有单品做向量相似度计算，判断重复购买风险。
3. 看值不值得买：结合用户画像、场景、预算、风格偏好，输出适合度评分和购买建议。

虚拟试衣、情绪穿搭、天气穿搭、Agent 对话、MCP 工具等能力保留为扩展亮点，不作为答辩和简历的第一主线。

## 2. 项目完成标准

| 完成标准 | 验收方式 | 当前目标 |
|---|---|---|
| 能演示 | 3-5 分钟跑通上传图片、识别、相似度分析、适合度评估、购买建议 | 固定一组演示账号和样例图片 |
| 能部署 | 后端 FastAPI 可启动，前端可访问，核心接口可调用 | README/操作文档中保留启动步骤 |
| 能讲清价值 | 能说明系统解决重复购买、搭配犹豫、主观决策不稳定的问题 | 用一句话总结业务价值 |
| 有指标 | 至少统计识别准确率、重复购买判断准确率、平均响应耗时 | 初版用 20 条样本，简历前扩到 50-100 条 |
| 有边界 | 不再新增大功能，只修演示路径、文档、测试和稳定性问题 | 冻结主流程之外的需求 |

## 3. 固定演示脚本

演示时不要随意点击功能。建议使用下面的固定路径：

1. 登录系统，展示用户画像：身高、体型、肤色、风格偏好、预算。
2. 进入衣橱，展示已有服饰。
3. 上传或选择一件待购买服饰图片。
4. 系统展示识别结果：品类、颜色、风格、主要特征。
5. 进入相似度分析，展示 Top-N 相似单品和重复购买风险。
6. 进入适合度评估，展示颜色、版型、风格、场景匹配理由。
7. 输出最终购买建议：推荐购买、谨慎购买或不建议购买。

演示结尾建议固定为：

> 这个系统把原本依赖主观感觉的买衣服过程，转化成图像识别、向量检索和用户画像评分驱动的可解释购买决策流程。

## 4. 本周停止新增的功能

以下功能本周不再继续扩展，只保留可演示状态：

- 虚拟试衣更多模式

- 天气穿搭更多城市逻辑
- Agent 新工具
- 新模型接入
- 大规模 UI 重构

- 主流程稳定性
- 演示样例准备
- 量化评测
- 文档和简历材料
- 明显 bug 修复
