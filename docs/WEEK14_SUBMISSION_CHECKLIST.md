# 第 14 周项目收尾提交清单

## 1. 主项目选择

主项目：衣服穿搭决策助手

选择理由：

- 比法律 AI 多智能体系统和 Intelligent-Medical-System 更贴近完整产品闭环。
- 同时覆盖图像识别、向量检索、推荐决策、用户画像、FastAPI、Flutter 和 Agent 工程能力。
- 更容易演示“输入图片 -> 分析 -> 决策建议”的完整流程。

## 2. 项目完成定义

项目完成不等于继续新增功能，而是达到：

- 能演示：主流程 3-5 分钟跑通。
- 能部署：后端、前端、核心接口可启动和访问。
- 能讲清价值：解决重复购买、搭配犹豫和购买决策不稳定。
- 有量化指标：准确率、耗时、样本量、覆盖类别。
- 有简历表达：背景、动作、结果清晰。

## 3. 简历项目描述

推荐使用 `docs/RESUME_PROJECT_WRITEUP.md` 中的最终版本，并在评测完成后填入真实数字。

当前占位句：

> 基于 FastAPI + Flutter 构建 AI 衣服穿搭决策助手，使用 CLIP/FashionCLIP 对服饰图片进行品类、颜色、风格识别与图像特征向量提取，并基于余弦相似度实现衣橱相似单品检索和重复购买预警；结合用户画像、场景、预算、风格偏好等维度设计适合度评分模型，输出可解释的购买决策建议。在 N 张服饰图片测试集中品类识别准确率达到 X%，在 N 组衣服对中重复购买判断准确率达到 Y%，单次购买决策平均耗时约 Z 秒。

## 8. 最终答辩话术

> 我的项目不是继续堆穿搭功能，而是收束成一个购买决策闭环。系统先识别衣服，再用向量相似度判断是否和衣橱已有单品重复，最后结合用户画像、场景和预算给出可解释购买建议。这样可以把用户主观、模糊的买衣服判断，变成有证据、有评分、有指标的 AI 决策流程。
