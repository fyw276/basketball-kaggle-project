# 衣服穿搭决策助手量化评测方案

## 1. 评测目标

本评测只服务于项目收尾和简历表达，不追求论文级实验。目标是拿到真实、可解释、能复现的数字：

- 服饰识别准确率
- 重复购买判断准确率
- 购买推荐合理性
- 单次完整流程耗时
- 系统覆盖范围

## 2. 当前数据基础

仓库中已有 `data/purchase_recommendation_test_data.csv`，当前包含 20 条购买推荐样本，可作为初版评测集。

建议在简历最终版前扩展到：

| 评测集 | 建议数量 | 用途 |
|---|---:|---|
| 服饰识别样本 | 50-100 张 | 统计品类、颜色、风格识别准确率 |
| 相似/不相似衣服对 | 30-50 组 | 统计重复购买判断准确率 |
| 用户画像 + 购物场景 | 20-30 组 | 统计购买推荐合理性 |
| 端到端流程 | 20 次 | 统计平均响应时间 |

## 3. 指标口径

### 3.1 服饰识别准确率

定义：

```text
识别准确率 = 识别正确样本数 / 总样本数
```

建议拆成 3 个指标：

| 指标 | 正确标准 |
|---|---|
| 品类识别准确率 | 预测品类与人工标注品类一致 |
| 颜色识别准确率 | 主色系一致即可，不要求色号完全一致 |
| 风格识别准确率 | 预测风格与人工标注或商品元数据一致 |

简历可写：

> 在 N 张服饰图片测试集中，品类识别准确率达到 X%，主色系识别准确率达到 Y%。

### 3.2 重复购买判断准确率

定义：

```text
重复购买判断准确率 = 判断正确的衣服对数量 / 衣服对总数
```

建议人工标注三类：

| 标签 | 含义 |
|---|---|
| duplicate | 高度相似，存在重复购买风险 |
| related | 有相似风格，但不完全重复 |
| distinct | 明显不同，不构成重复购买 |

系统输出可按相似度阈值映射：

| 相似度区间 | 系统判断 |
|---|---|
| `>= 0.80` | 高重复风险 |
| `0.60 - 0.79` | 中等相似 |
| `< 0.60` | 差异较大 |

阈值需要根据真实测试结果微调，文档中保留最终阈值即可。

简历可写：

> 基于 CLIP 图像向量与余弦相似度实现重复购买预警，在 N 组衣服对测试中判断准确率达到 X%。

### 3.3 购买推荐合理性

定义：

```text
推荐合理率 = 系统建议与人工标注一致或基本一致的样本数 / 总样本数
```

建议人工标注三类：

| 标签 | 含义 |
|---|---|
| recommend | 推荐购买 |
| cautious | 谨慎购买 |
| reject | 不建议购买 |

系统输出需要解释至少 3 个维度：

- 是否与已有衣物重复
- 是否匹配用户画像
- 是否匹配场景和预算

简历可写：

> 结合用户画像、场景和预算构建多维评分模型，在 N 条购物样本中推荐结论与人工标注一致率达到 X%。

### 3.4 平均响应耗时

定义：

```text
平均响应耗时 = 多次完整流程耗时总和 / 测试次数
```

建议分别记录：

| 流程 | 记录方式 |
|---|---|
| 图像识别耗时 | 上传图片到返回识别结果 |
| 相似度分析耗时 | 发起分析到返回 Top-N |
| 购买建议耗时 | 发起评估到返回最终建议 |
| 端到端耗时 | 上传图片到拿到最终建议 |

简历可写：

> 单次购买决策分析平均耗时约 X 秒，相比人工对比衣橱和场景判断节省约 Y% 时间。

1. 将购买推荐样本从 20 条扩展到 50-100 条。
2. 将相似度评测样本补到 30-50 组衣服对。
3. 固定一版阈值，不要每次演示临时调整。
4. 保留原始评测表，防止面试追问数字来源。
5. 简历只写已经测过的数字，不写估计值。
