# 📊 模型准确率说明

## 🎯 当前状态：MVP（最小可行产品）

当前图像识别系统使用的是 **ImageNet 预训练的 MobileNetV2** 模型，**未针对服饰数据进行微调**。这是一个 MVP 实现，主要用于：

1. ✅ 验证系统架构和 API 设计
2. ✅ 测试完整的数据流程
3. ✅ 提供基础的图像识别功能
4. ❌ **不保证高准确率**

### 你的测试图片

**图片内容**：深蓝色上衣，带格子衬衫领子和袖口

**识别结果**：
- **品类**: "上衣" ✅ **正确**
- **主色**: "绿" ❌ **不正确**（应该是"蓝"）

## 🤔 为什么不准确？

### 1. 品类识别（相对准确）

**原理**：
- 使用 ImageNet 的 1000 个类别
- 映射到 6 个服饰品类（上衣/裤子/裙子/外套/鞋/包）
- 例如：ImageNet 类别 610-640 映射到"上衣"

**准确率**：
- ✅ 大类识别（上衣 vs 裤子）：较准确
- ⚠️ 细分类别（T恤 vs 衬衫）：不准确

**你的结果**：
- ✅ 正确识别为"上衣"

### 2. 颜色识别（不准确）

**原理**：
- 使用 K-Means 聚类提取主色
- 将 RGB 颜色映射到 10 个标准色系

**问题**：
1. **背景干扰**：米色背景可能影响聚类结果
2. **光照影响**：阴影和高光改变颜色感知
3. **多色物体**：格子衬衫领子和袖口有黑白格子
4. **颜色映射规则简单**：HSV 阈值可能不准确

**你的结果**：
- ❌ 识别为"绿"，实际是"蓝"
- 可能原因：
  - 深蓝色在某些光照下 HSV 值接近绿色范围
  - 背景或格子部分影响了聚类结果

### 3. 风格识别（完全不准确）

**原理**：
- 使用 ImageNet 类别映射到 12 个风格标签
- 例如：类别 610-620 映射到"通勤"

**问题**：
1. **映射规则过于简单**：ImageNet 不是为服饰风格设计的
2. **阈值设置不当**：当前阈值 0.3，归一化后大部分风格都超过阈值
3. **没有真正的风格分类能力**：只是基于 ImageNet 类别的启发式映射

**你的结果**：
- ❌ 返回了所有 12 个风格标签
- 原因：归一化后的分数都超过了 0.3 阈值

## 🛠️ 如何提高准确率？

### 短期改进（无需训练模型）

#### 1. 提高颜色识别准确率

**方法**：
- 改进 K-Means 聚类参数
- 添加背景去除预处理
- 优化 HSV 颜色映射规则
- 增加颜色权重（忽略小面积颜色）

**预期提升**：40% → 60%

#### 2. 修复风格识别

**方法**：
- 提高阈值（0.3 → 0.5 或 0.6）
- 限制返回的风格数量（最多 3 个）
- 改进归一化算法

**预期提升**：20% → 40%

#### 3. 添加后处理规则

**方法**：
- 基于品类限制风格（例如：鞋不应该有"甜美"风格）
- 基于颜色调整风格（例如：黑色更可能是"正式"或"朋克"）
- 添加置信度阈值

**预期提升**：整体 +10-15%

### 长期改进（需要训练模型）

#### 1. 收集服饰数据集

**需求**：
- 品类：每个品类 1000-2000 张图片
- 颜色：标注主色和辅助色
- 风格：标注 1-3 个风格标签

**总计**：6000-12000 张标注图片

#### 2. 微调 MobileNetV2

**方法**：
- 冻结 MobileNetV2 主干网络
- 添加自定义分类头
- 使用服饰数据集训练

**预期准确率**：
- 品类：90-95%
- 颜色：80-90%
- 风格：70-85%

#### 3. 模型优化

**方法**：
- 量化模型（减小体积）
- 优化推理速度
- 添加数据增强
